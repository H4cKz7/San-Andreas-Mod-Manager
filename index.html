IncludeMods

This profile is checked first, then its parents, and the first value found wins. $current is the profile selected right now. A mod marked exclusive is hidden from every profile except that one and the profiles that inherit from it. UseIfModule takes a single module name.

Ignored files

Patterns for the active profile. They are matched against each file’s path inside its mod, in every mod. Use * for a wildcard, e.g. *.asi or sub/**.
