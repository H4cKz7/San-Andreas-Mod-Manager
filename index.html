Profile settings

Parents
UseIfModule
IncludeMods

This profile is checked first, then its parents, and the first value found wins. $current is the profile selected right now. A mod marked exclusive is hidden from every profile except that one and the profiles that inherit from it. UseIfModule takes a single module name.

Ignored files

Ignored mod folders and patterns for the active profile. Patterns are matched against each file’s path inside its mod, in every mod. Use * for a wildcard, e.g. *.asi or sub/**.

File conflicts

Mods that contain a file with the same name. The one with the higher priority wins under the current profile.

Trash0

Removed mods and files wait here until you restore them or delete them for good.

Plugins0

DLLs in .data/plugins, with priorities saved to plugins.ini. Priority 0 disables a plugin and a blank value uses the default.

Mod Loader not found

  

  

    Mod Loader only
    Install Mod Loader with the mod installer. Choose a .zip, .rar or .7z archive, or the extracted folder that contains modloader.asi. Its files are copied into the game folder.
    

  

  

    Essentials Pack
    Install the Essentials Pack with the mod installer. Choose a .zip, .rar or .7z archive, or the extracted folder. It includes Mod Loader, CLEO, SilentPatch and more, and it replaces gta_sa.exe (the original is backed up).
